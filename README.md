# Personal Portfolio

A modern, responsive personal portfolio website built with Next.js and Tailwind CSS.
https://anushamahajan-nvdmviu5a-anushamahajans-projects.vercel.app/

## Features

- Single-page application with smooth scrolling navigation
- Responsive design that works on all devices
- Dark theme optimized for readability
- Sections for About, Experience, Projects, and Contact
- Built with TypeScript for type safety

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the development server:
   ```bash
   npm run dev
   ```

3. Open [http://localhost:3000](http://localhost:3000) in your browser.

## Customization

- Update personal information in `app/page.tsx`
- Replace placeholder images in the `public/` folder
- Modify styles using Tailwind CSS classes
- Add your own projects and experience details

## Build for Production

```bash
npm run build
npm start
```

## Deploy

This project can be easily deployed to Vercel, Netlify, or any static hosting service.
